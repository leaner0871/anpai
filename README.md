# 时序 · 课表 / 日程 / 记账

一个单文件、本地优先的个人时间管理工作台。打开即用，不需要注册、不需要服务器，数据只存在你自己的浏览器里。

## 在线使用

部署后直接访问（GitHub Pages 地址见仓库 Settings → Pages）。

手机上打开后，浏览器菜单里选「添加到主屏幕」，就能像 App 一样全屏使用；由于带 Service Worker，**打开过一次之后断网也能用**。

## 能做什么

- **课程表**：周视图网格，固定课程块，支持单双周、地点标注
- **日程**：任务块和课程融合在同一张网格里，拖动改时间、跨列换天、拖底边改时长
- **自动排程**：给任务填截止时间和预估耗时，页面按「紧迫度」自动装箱到你的空闲时段，可手动拖动覆盖
- **今日执行流**：今天该做什么按紧迫度排序，点开能看到「为什么排在这」（距截止、可支配时间、评分拆解）
- **长期规划**：目标 → 任务 → 一键投入日程
- **记账**：一句话记账（`午饭 15 微信`）、账户余额、分类统计、对账；支持导入微信/支付宝 CSV 账单
- **指令框**：每个页面底部有一行输入框，用中文说话就能建任务、挪时间、完成、加课、记账
- **导入导出**：JSON 整份备份、`.ics` 日历导出、`.ics` 课表导入

## 数据

- 全部存在浏览器的 `localStorage`（键名 `shixu.v1`），**跟网址绑定**
- 换设备 / 换网址：设置页「导出备份」→ 新地址「导入备份」
- 清浏览器数据、无痕模式会丢，建议定期导出

## 可选：接入 AI

设置页填一个 OpenAI 兼容的 Key（例如 DeepSeek），当本地指令解析没听懂时，会调用模型理解你的话，并在执行前弹出确认卡。

不填 Key 也能用，只是指令框只认本地能解析的说法。

## 技术

纯 HTML + CSS + JS 单文件，无构建、无依赖、无后端。
